# 云雀智能助手 产品手册

## 一、产品概述

云雀智能助手是面向企业的知识库问答产品，支持文档上传、语义检索与答案溯源。产品定位是「让企业沉淀的文档真正被用起来」。

核心能力包括：多格式文档解析、混合检索、引用溯源、多轮对话、私有化部署。

## 二、部署方式

产品提供三种部署方式：

1. SaaS 版：开箱即用，数据存储于云端，按调用量计费，适合 50 人以下团队快速试用。
2. 私有化部署：交付 Docker 镜像，部署在客户自有服务器或专有云，数据不出内网，适合金融、医疗等强合规行业。
3. 混合部署：检索与存储留在本地，仅将脱敏后的文本片段发送至云端大模型推理，兼顾效果与合规。

私有化部署的最低配置要求为 8 核 CPU、32GB 内存、200GB 磁盘；如需本地运行 7B 级别模型，建议配备 24GB 显存以上的 GPU。

## 三、接口与限流

开放 API 采用 RESTful 风格，鉴权方式为 Bearer Token，Token 在管理后台「开发者设置」中生成，有效期 90 天。

默认限流策略：免费版每分钟 60 次请求，专业版每分钟 600 次，企业版按合同约定。超出限流返回 HTTP 429，响应头 `Retry-After` 给出建议重试秒数。

流式接口使用 SSE（Server-Sent Events），单次请求最长持续 120 秒。

## 四、数据安全

所有上传文档在传输层使用 TLS 1.2 以上加密，存储层使用 AES-256 加密。文档默认保留 90 天，可在后台配置为永久保留或 7 天自动清理。

产品支持细粒度权限：按部门、按文档库、按标签三种维度控制可见范围。所有问答操作留痕，审计日志保留 180 天。

SaaS 版已通过等保三级认证，私有化部署版本提供等保测评所需的全部材料清单。

## 五、计费说明

SaaS 版按「文档页数 + 问答次数」计费：文档解析 0.02 元每页，问答 0.05 元每次。每月前 1000 次问答免费。

年付享 8.5 折，三年付享 7 折。教育与非营利机构可申请 5 折优惠。
